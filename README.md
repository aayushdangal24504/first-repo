# Avyukta Life

A fully local personal productivity and life management desktop app.

## Stack

- Electron for local desktop runtime
- React + TypeScript for UI
- TailwindCSS for design system
- SQLite through `better-sqlite3` for local data
- Zustand for state management
- Framer Motion for animation
- TipTap planned for rich text editing

## Run Locally

```bash
npm install
npm run dev
```

## Local-Only Promise

No cloud hosting, no paid server, no authentication, no subscriptions, and no multi-user backend. Data is stored in SQLite and local filesystem folders on this laptop.
